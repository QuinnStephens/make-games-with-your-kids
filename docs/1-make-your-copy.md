# Step 1: Make your own copy

In this step you'll sign up for GitHub (free) and copy this starter kit into your account. Your copy is where your family's games will live.

## Sign up for GitHub

If you already have a GitHub account, skip to [Copy the starter kit](#copy-the-starter-kit).

1. Go to [github.com/signup](https://github.com/signup).
2. Type your email address, make up a password, and pick a **username**. The username will show up in a few places (like your project's address on GitHub), so pick something you're happy with. Your family name or a nickname works well.
3. GitHub asks you to solve a small puzzle to prove you're a person, then emails you a code. Type the code in.
4. GitHub may ask a few questions about how you'll use it. You can answer them or look for a **Skip** link. If it asks you to pick a plan, choose **Free**.

That's it. You now have a GitHub account.

## Copy the starter kit

1. Make sure you're signed in to GitHub, then open the starter kit's page: [github.com/quinnstephens/make-games-with-your-kids](https://github.com/quinnstephens/make-games-with-your-kids).
2. Near the top right, click the green **Use this template** button, then **Create a new repository**.
3. Fill in the form:
   - **Owner**: your username (it's probably already picked).
   - **Repository name**: a name for your games, with dashes instead of spaces. For example, `our-family-games`.
   - **Description**: optional. Something like "Games we made together".
   - **Public or Private**: we suggest **Private**, so only you can see the files (including your kids' drawings). Your website still works either way. You can change this later.
4. Click **Create repository**.

After a few seconds you'll see your own copy, with a list of files and folders like `catch-the-stars`, `find-the-bunnies` and `games.json`. Below the list you'll see the same guide you're reading now.

> **Tip:** Bookmark this page. It's your project's home on GitHub, and you'll come back to it to see changes.

## What's in there?

You don't need to open any of these, but in case you're curious:

| File or folder | What it is |
| --- | --- |
| `index.html` | The game menu that shows all your games. |
| `games.json` | The list of games the menu shows, and the name of your site. |
| `catch-the-stars/`, `find-the-bunnies/` | The two example games. Each game gets its own folder. |
| `images/` | The pictures on the menu, one per game. |
| `back-to-launcher.js` | A small piece shared by every game that adds the "Menu" button. |
| `CLAUDE.md` | Instructions for Claude on how to make games for this site. |
| `docs/` | These guides. |

## Optional: give your site its own name

The menu says "Our Family Games" at the top. To change it right now, without Claude:

1. In your repository, click `games.json`.
2. Click the pencil icon (✏️) near the top right of the file to edit it.
3. Change `Our Family Games` on the second line to whatever you like, keeping the quote marks around it. For example: `"siteTitle": "The Garcia Game Zone",`
4. Click the green **Commit changes...** button, then **Commit changes** again in the box that pops up.

(You can also just ask Claude to do this later.)
